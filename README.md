### About

I work end-to-end across the data stack: ingesting messy public feeds, modelling them
into something dimensional and trustworthy, and shipping the result as a dashboard,
a model, or an API that runs on its own schedule.

- 🏗️ **Analytics engineering** — dimensional modelling with dbt, tested and documented
- 🌊 **Data engineering** — lakehouse pipelines on Databricks (Delta Lake, Unity Catalog, medallion)
- 🤖 **AI / ML** — retrieval-augmented search, embeddings, MLflow-tracked models
- ⚙️ **Automation** — everything above refreshed daily by GitHub Actions, not by me
